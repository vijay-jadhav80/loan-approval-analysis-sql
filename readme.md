# 📊 Loan Approval Analysis using SQL

This project focuses on analyzing a **Loan Approval dataset using MySQL** to understand the factors associated with loan approval and rejection.

The analysis covers applicant demographics, financial information, credit history, employment status, loan amounts, and property areas.

## 🎯 Project Objective

The main objective of this project is to use SQL to explore the loan dataset and identify patterns and factors that may influence **loan approval and rejection**.

## 📚 Analysis Performed

### 🔹 Dataset Overview

* Checked the structure and columns of the dataset
* Calculated the total number of loan applications
* Counted the total number of columns
* Analyzed approved and rejected loan applications
* Calculated the overall loan approval percentage
* Checked for missing values
* Verified loan IDs for duplicates

### 🔹 Applicant Demographics

Analyzed loan applications based on:

* Gender
* Married status
* Dependents
* Education
* Employment status
* Age groups
* Property area

### 🔹 Financial Analysis

Analyzed:

* Applicant income
* Co-applicant income
* Loan amount
* Loan term
* Income categories
* Loan amount categories
* Loan-to-income ratio

### 🔹 Credit History Analysis

Compared loan approval rates based on **credit history** and analyzed:

* Applicants with good credit history
* Applicants with poor credit history
* Average income by credit history
* Average loan amount by credit history

### 🔹 Approval & Rejection Analysis

Explored:

* Approval rate by employment status
* Approval rate by property area
* Approval rate by education
* Approval rate by age group
* Approval rate by dependents
* Approval rate by credit history
* Employment status combined with credit history
* Highest rejection-rate property areas

## 💡 Key Insights

Some important findings from the analysis:

1. **Credit history** is an important factor associated with loan approval.
2. **Salaried applicants** represent a significant portion of approved loans.
3. **Graduates** showed a higher loan approval rate compared with non-graduates.
4. Applicant **income and loan amount** were analyzed to understand their relationship with approval.
5. Applicants with **good credit history and higher income** generally showed stronger approval outcomes.
6. Property area, employment status, education, and age groups were also compared to identify approval patterns.
